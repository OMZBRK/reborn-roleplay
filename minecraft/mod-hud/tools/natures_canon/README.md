# natures_canon — icônes canoniques des cinq natures de chakra

Source des symboles de nature du mod (`textures/gui/nature/<nature>.png`), convertis par
`tools/gen_natures_textures.py` avec le pipeline des blasons de clan (`tools/gen_clan_emblemes.py`).
